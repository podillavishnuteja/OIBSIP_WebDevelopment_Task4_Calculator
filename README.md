# OIBSIP_WebDevelopment_Task4_Calculator

## Project Title
Calculator

## Objective
The objective of this project is to design and develop a responsive web-based calculator using HTML, CSS, and JavaScript that performs basic arithmetic operations efficiently and provides an intuitive user experience.

## Features
-Basic arithmetic operations:

1.Addition (+)

2.Subtraction (-)

3.Multiplication (×)

4.Division (÷)

5.Modulus (%)

-Parentheses support ( )

-Decimal support (.)

-Natural Log button (ln) (UI included – logic can be extended)

-Keyboard input support

-Clear display (C)

-Backspace support

-Responsive design (mobile-friendly)

-Error handling for invalid expressions

## Technologies Used
1. HTML5
2. CSS3
3. JavaScript

## Project Structure
calculator-project/

├── index.html      # Main HTML structure

├── style.css       # Styling and layout

├── script.js       # Calculator logic

└── README.md       # Project documentation

## How to Run the Project
1.Download or clone this repository.

2.Make sure all files are in the same folder:

-index.html

-style.css

-script.js

3.Open index.html in your browser.

## How It Works
1.The display value is updated using appendToDisplay().

2.The calculate() function evaluates the expression using JavaScript’s eval() function.

3.Error handling ensures invalid expressions don’t break the app.

4.Keyboard events are handled using addEventListener('keydown').

## Outcome
The successful completion of this project resulted in a fully functional, responsive web-based calculator capable of performing basic arithmetic operations with both mouse and keyboard input support.
